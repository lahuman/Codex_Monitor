# Monitoring insights

## Why
Show quota reset/freshness/status and local observation trends without relay statistics.

## What Changes
Add reset countdown, quota health summary, poll schedule, plan/status, bounded persistent history, 24-hour graphs, comparable one-hour percentage-point decrease, and configurable per-account in-app low-quota alerts. Preserve unknowns and avoid interpreting reset changes as consumption. No token estimates or OS notifications.
